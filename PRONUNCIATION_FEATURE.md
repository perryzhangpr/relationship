# Pronunciation Feature Documentation

## Overview
The pronunciation feature is designed to assist users in understanding and practicing correct pronunciation of various words and phrases. This feature is integrated into the application to enhance user experience and facilitate language learning.

## Components
- **Audio Player**: Plays the pronunciation audio for the selected word.
- **Text Display**: Shows the word or phrase being pronounced.
- **Replay Button**: Allows users to listen to the pronunciation again.
- **Record Feature**: Enables users to record their voice for comparison.

## Build Instructions
To build the pronunciation feature, follow these steps:
1. Ensure you have the latest version of Node.js and npm installed.
2. Clone the repository:
   ```bash
   git clone https://github.com/perryzhangpr/relationship.git
   cd relationship
   ```
3. Checkout to the feature branch:
   ```bash
   git checkout feat/pronunciation-panel
   ```
4. Install dependencies:
   ```bash
   npm install
   ```
5. Build the project:
   ```bash
   npm run build
   ```

## Usage Examples
1. **Using the audio player**:
   - Select a word from the list.
   - Click the play button to hear the pronunciation.
   
2. **Recording your pronunciation**:
   - Click on the record button and pronounce the word.
   - Stop the recording and compare with the original audio.

This feature aims to improve user engagement and provide a more interactive learning environment.
